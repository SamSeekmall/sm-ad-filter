# 0.4.4 界面与体验修复

按 2026-10-19 UI/UX 审查清单修复 14 项（P0/P1/P2）：
- 品牌：工具栏、扩展页和上游页面全部换成 SM 绿色 S 图标（`sm/brand/`，含关闭态灰色版）；上游页面主色由蓝改为品牌绿；上游“备份/还原/重置”隐藏，改为指向控制中心。
- 暂停：显示剩余时间或“关闭浏览器后恢复”；按钮换成播放图标；暂停期间过滤模式显示“标准（恢复后生效）”且不可修改；新增 1 小时时长；时长统一叫“10 分钟 / 1 小时 / 到关闭浏览器”。
- 术语：三档统一为 轻度 / 标准（推荐）/ 强力（SM 页面与上游 zh_CN、zh_TW 词条）。
- 弹窗内排障：暂停后直接问“网页正常了吗”，可降一档并恢复保护或去反馈；步骤存在会话存储，弹窗关闭再打开可继续。
- 弹窗内隐藏元素：“这次先隐藏 / 以后都隐藏 / 管理本站已隐藏的元素”直接调用引擎脚本，不再跳转上游弹窗。
- 弹窗显示“本页已触发过滤规则 N 次”（依赖 activeTab 授权；读不到时不显示）。
- 控制中心改为左侧导航 + 分页（当前网站 / 规则 / 备份与撤销 / 反馈 / 诊断与关于），窄屏为吸顶标签；首次使用清单与保护状态不再矛盾，推荐规则只保留一个入口。
- 反馈区去掉用户自填仓库地址；仓库与支持联系方式改由 `release.json`（repository、supportContact）配置，未配置时提示复制报告交给提供者。
- 统一设计变量 `sm/tokens.css`（颜色、圆角、焦点色、暗色模式）；次要按钮边框对比度 3.15:1；弹窗支持暗色。
- 空状态与禁用：无历史时禁用撤销、无订阅时禁用更新、同步未开启时隐藏同步按钮；危险操作改为“再点一次确认”，不再弹浏览器原生对话框；文件导入改为中文按钮。

# 0.4.3 可靠性与可恢复性

导入失败现在会连同临时暂停（到期时间、子域例外）一起回退；完整设置、规则编辑器和导入订阅进入同一个写入队列；修改操作带编号，超时后核对结果而不重复提交；浏览器中断导入后，下次启动自动核对并回退。控制中心增加“开始使用”清单、“网页显示异常？分步排查”和诊断信息复制。Cookie 自动拒绝关闭时，普通网页不再唤醒后台。构建增加上游补丁契约、目录锁定、文件清单和可重复构建检查。

**不等于性能已达标。** 弹窗延迟没有在 Windows Chrome / Edge 上重新测量；性能门槛（`sm/perf-gates.json`）是未校准的建议值，当前没有任何设备通过它。完整的实施状态与未解决项见 IMPLEMENTATION-MATRIX-043.md，反馈流程见 SUPPORT-SM.md，试用材料见 PILOT-PLAN-SM.md。

# SM 净览（本地试用版）

Chrome / Edge 广告与跟踪过滤扩展，基于 uBlock Origin Lite 的独立修改版本，非官方产品。功能对应见 FEATURES-SM.md，测试证据见 QA-SM.md。

## 安装

1. 解压 chromium 安装包到固定目录。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择含 manifest.json 的目录。
4. 固定扩展到工具栏，打开“控制中心”，启用中文推荐规则，检查网站权限与实际保护状态。
5. 刷新网页。网页异常时可暂停 10 分钟或本次浏览器会话，之后自动恢复。

不要同时启用多个过滤扩展来判断本产品效果。浏览器受保护页面、商店页面不支持过滤。首次安装保持上游默认模式；中文推荐规则由用户主动启用。

## 本版功能

- 中文工具栏、控制中心、站点保护与权限诊断；保留上游完整设置、元素选择/恢复、导入订阅和高级规则。
- 10 分钟和会话暂停、自动恢复；中文推荐与减少打扰两组附加规则预设。
- 订阅刷新、最近成功/尝试及错误状态；失败保留旧规则。内置规则随扩展包更新。
- 按域名查看和删除元素规则、最近操作撤销、恢复快照。
- v2 配置导出、导入预览确认，检测预览后配置变化，失败时尝试自动回退。
- 可选浏览器同步，手动读取/上传/删除、容量检查、版本冲突提示；跨浏览器迁移使用备份文件。
- 可选 Cookie 拒绝：OneTrust / Cookiebot 标准拒绝按钮，默认关闭；关闭时网页脚本只读本地开关，不唤醒后台。
- 开始使用清单、网页异常分步排查、诊断信息复制；导入失败/中断自动回退并提示。
- 最近规则命中诊断，区别阻止、替换、放行；不将命中数称为广告数量或节省流量。
- 脱敏反馈预览、复制、下载、打开已配置 GitHub 仓库的问题表单。

Cookie 功能不代表清除既有 Cookie，也不能证明服务端拒绝同意。同步依赖浏览器账户、扩展 ID 和浏览器同步服务；当前只验证本机读写，不保证多设备同时写入的原子性。配置超过 7 KB 使用文件迁移。完整设置语言跟随浏览器，SM 控制中心使用简体中文。

## 版本、权限与隐私

产品版本 0.4.3，浏览器升级版本 2026.1019.8，上游引擎 2026.1012.1545。本地加载版没有商店自动升级，需手动更新、保留旧包并重新加载，详见 RELEASE-SM.md。

SM 不设置账号、遥测或自有服务器。网站访问和脚本权限用于内容过滤；storage 保存配置；DNR 执行网络规则；offscreen/userScripts 支持规则处理；alarms 调度恢复和更新。规则命中诊断权限可选。订阅会请求提供方；同步与 GitHub 反馈由用户主动开启。详见 PRIVACY-SM.md。
