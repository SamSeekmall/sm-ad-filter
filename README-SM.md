# SM 净览 0.1.0（本地试用版）

Chrome / Edge 广告过滤扩展，基于 uBlock Origin Lite 的独立修改版本，非官方产品。

## 安装

1. 解压安装包到固定目录。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。
4. 将 SM 净览固定到工具栏，点击面板底部“中文指南”。可查看实际状态并启用中文规则。
5. 刷新已打开的网页再验证效果。不要同时启用其他广告过滤扩展进行对比测试。

上游功能：网络广告与跟踪过滤、站点过滤模式、元素选择/恢复、自定义过滤、规则订阅管理。
SM 修改：独立扩展名称、中文引导页、实际状态读取、中文规则快捷启用及读回验证、工具栏指南入口。
完整设置保留上游界面，语言跟随浏览器。中文指南固定使用简体中文。

## 权限和数据

保留上游 manifest 权限。所有网站访问及 scripting 用于内容过滤；storage 保存设置；DNR 执行网络规则；offscreen/userScripts 支持规则处理；alarms 调度后台任务。SM 不增加账号、遥测或服务器。上游列表更新/导入订阅会访问提供方；报告功能由用户主动打开。不要向反馈中粘贴敏感网址。

## 限制与更新

无法过滤浏览器受保护页面。视频广告、弹窗和反拦截效果需按具体网站验证，无法保证百分之百屏蔽。网页异常时使用站点例外并刷新。试用包没有商店自动更新；升级需从明确提交重新打包，在扩展管理页重新加载。卸载会删除扩展设置；更新前可在完整设置中备份。
